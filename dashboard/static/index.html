      About this project

      An end-to-end applied AI case study referencing Moderna's public mRNA work: patient-risk modeling, Transformer self-attention mathematics, retrieval over regulatory guidelines, and schema-validated report generation.

      This interface is the design layer. Values appear only after the corresponding module produces them. Nothing on screen is simulated.
